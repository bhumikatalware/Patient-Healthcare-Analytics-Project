# Patient-Healthcare-Analytics-Project

Overview

This project is an end-to-end Data Analytics project focused on analyzing healthcare data using Python, SQL, and Power BI. The project covers the complete analytics workflow, including data loading, exploratory data analysis (EDA), data cleaning, SQL-based analysis, dashboard creation, reporting, and presentation preparation.

The main objective is to transform raw healthcare data into meaningful insights that help understand patient demographics, hospital visits, treatment costs, lab test trends, and healthcare performance indicators.

Dataset

The dataset contains healthcare-related information divided into multiple tables:

Patient Data – Patient demographics, age, gender, blood type, insurance provider, chronic conditions
Doctor Data – Doctor specialties, experience, and hospital details
Visit Data – Patient visit records, diagnoses, visit type, and follow-up information
Treatment Data – Treatment details, costs, outcomes, and status
Lab Test Data – Test names, results, abnormalities, and reference ranges
